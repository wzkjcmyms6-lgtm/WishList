Cuenta de Ositos 🐻‍❄️🐻

Para arreglar el acceso de una vez. Acá puedes ver la contraseña mientras la escribes, cosa que la consola de Firebase no deja hacer.

¿Cuál de los dos botones uso?
Toca Entrar primero. Si dice que no coincide, toca Crear cuenta: si responde que ya existe, entonces el correo está bien y lo que falla es la contraseña — bórrala en Firebase → Authentication → Users → ⋮ → Borrar cuenta, y vuelve acá a tocar Crear cuenta con la contraseña que quieras.
